开始看学校的时候，我第一反应是去搜"计算机考研院校排名"。

搜完更迷茫了：排名高的一大堆，但没人告诉我**哪个是我能考上的**。

后来换了个思路——不看排名，改成填表。每所学校都要把这十一格填满，
填不满的就不进入候选名单。

## 一、三个硬门槛

| 要查的 | 为什么重要 |
| --- | --- |
| **学硕还是专硕** | 科目不同（数一英一 / 数二英二），名额差异也很大 |
| **是否考 408** | 决定复习体量。四门课和一门自命题，是完全不同的工作量 |
| **数一还是数二 / 英一还是英二** | 直接决定公共课重心 |

这三格有个坑：**不要用去年的资料。**

2026 年 7 月的统计是，已经有近百所高校把计算机、电子信息、人工智能专业
从自命题改成了 408 统考。所以查之前先去目标院校的研招网确认最新科目。

在确认之前，一律按 408 四门复习——覆盖范围最大，后期收缩容易，反过来几乎不可能。

## 二、三个"能不能考上"

排名决定不了这个，下面三格才能：

| 要查的 | 红线 |
| --- | --- |
| **统考实际名额** | **必须剔除推免。** 学硕统招 < 8 人、专硕 < 20 人的，容错率太低 |
| **复录比** | 大于 1.5 : 1，说明复试刷人很狠 |
| **是否保护一志愿** | 不保护的学校，调剂生会直接挤占你的名额 |

"统考名额"这一格最容易看错。招生简章上写的数字通常**含推免**，
真正要查的是**拟录取名单**——那里才是统考实际录取的人数。

## 三、五个常见的坑

| 要查的 | 为什么 |
| --- | --- |
| 近 3 年复试线 | 看趋势，不要只看最新一年 |
| 专业课是否压分 | 压分严重 → 一旦需要调剂会很难 |
| 复试占比 | 超过 50% 的要慎重，初试高分也可能被刷 |
| 是否有机试门槛 | 部分院校要求 PAT 达到特定分数才能进复试 |
| 地域与就业资源 | 计算机非常看重实习，一线城市的双非有时比偏远 985 更好就业 |

## 两个关于"时机"的陷阱

**大小年。** 某校去年分数线骤降，今年极大概率反弹扎堆。只看去年数据会误判。

**改考红利。** 反过来，某校今年刚改考 408，第一年往往是"红利窗口"——
报考人数少、分数线低。这种窗口值得留意，但前提是你敢赌第一年。

## 时间安排

| 时间 | 做什么 |
| --- | --- |
| 2026.09 – 12 | 把三档院校库填起来，**按 408 复习** |
| 2027.01 – 06 | 边复习边圈定，关注改考动态与大小年 |
| 2027.06 | 全真模考（近 3 年 408 + 数学真题），锁定到 2 – 3 所 |
| 2027.09 – 10 | 招生简章发布，核实名额 / 科目 / 复试要求，正式定档 |

## 为什么用表格，而不是用排名

因为排名是别人给的，表格是自己填的。

排名告诉你"这所学校好不好"，表格告诉你"**这所学校我能不能上、值不值得上**"。
考研是概率事件，前者帮不了你，后者才帮得上。

十一格填完，剩下的其实只有三档：冲刺、匹配、保底。每一档留两三所，够了。
